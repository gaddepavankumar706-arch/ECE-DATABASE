# SBTET Student Connect

A modern, responsive, mobile-first web portal for Telangana State Board of Technical Education and Training (SBTET) diploma and polytechnic students. Built using vanilla modern JavaScript (ES Modules), CSS, and Firebase Authentication & Firestore.
